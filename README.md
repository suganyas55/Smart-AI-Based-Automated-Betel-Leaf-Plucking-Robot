# 🍃 Smart AI-Based Automated Betel Leaf Plucking Robot

An automated robotics and computer vision solution designed to identify mature betel leaves and pluck them precisely without damaging the plant.

---

### 📌 Project Overview
Betel leaf harvesting is labor-intensive and requires manual judgment. This project combines **Artificial Intelligence (Computer Vision)** with an **Embedded Robotic Arm** to automate the detection, selection, and harvesting process in real-time.

---

### 🛠️ Hardware & Software Stack

**Hardware Components:**
- Microcontroller (Arduino / ESP32 )
- Robotic Arm with Servo Motors
- Camera Module (Raspberry Pi Cam / WebCam)
- Power Supply Unit

**Software & Tools:**
- **Languages:** Python, Embedded C
- **AI/ML:** OpenCV, YOLO / TensorFlow (Leaf Detection)
- **IDE:** Arduino IDE / VS Code

---

### ⚡ Key Features
- **Real-time Leaf Detection:** Uses computer vision models to distinguish mature leaves from tender ones.
- **Automated Harvesting:** Controls robotic arm servo motors for precise cutting and plucking.
- **Non-destructive Mechanism:** Ensures zero damage to the main plant stem.
